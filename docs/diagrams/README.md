# Project Diagrams

This folder contains lightweight Mermaid diagrams for explaining the Legal RDF Explorer project.

Files:

- `overall-system-architecture.md` - full system architecture from data sources to web UI.
- `crawler-pipeline.md` - how Gazzetta and Normattiva data become RDF files.
- `knowledge-graph-data-model.md` - RDF knowledge graph model and main relationships.

These diagrams can be viewed directly in GitHub, many Markdown editors, and Mermaid-compatible tools.
